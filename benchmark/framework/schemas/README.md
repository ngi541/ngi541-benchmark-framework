# Persistent experiment contracts

Schema files in this directory describe machine-readable definitions and evidence files generated by the experiment framework. Each `*.schema.json` represents a bounded data contract: definitions, deployment, schedules, measurements, telemetry, scientific corpus, paired results or integrity metadata.

The schema directory is **not a directory of archived milestone revisions**. It documents the currently tracked contracts; future incompatible changes must use explicit schema versions. The core Python runtime checks invariants without requiring a third-party JSON Schema validator. External validation tooling may use the schema files independently.

The scientific identity excludes provider, node hostname, SSH target and local absolute path. Environment and deployment data is recorded separately and concrete execution provenance captures hardware, binaries, inputs, schedule and attempts.
